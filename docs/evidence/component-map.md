# Component map

The machine-readable map is `component-ledger.json`. At the current checkpoint, the independent client foundations implement and automate exact source pinning and offline bootstrap, deterministic OpenMW patch machinery, local protocol schemas/fixtures and a loopback fake-server harness, the pure native scaffold, the Lua architecture and source manifest, deterministic packaging and package/source audits, and pinned CI definitions.

The pure native and Lua checks remain deliberately separate from OpenMW and game proof. Run `./scripts/test/native.sh` for the direct warning-clean native suite, `./scripts/test/lua-unix.sh` on Unix when Lua is installed, or `./scripts/test/lua-windows.ps1` in PowerShell. The native command does not compile the engine, Lua structural/source-manifest checks do not prove Lua execution, and the fake server does not prove the Beast live wire.

Deferred components are the final `SYNTH`/`Synthserver` SHA import and migration plus cross-repository parity; the Beast serializer/transport; exact-pin OpenMW package-registration and media VFS-versus-decoder patches plus patched/control engine builds; Lua-runtime proof on an available host; Windows builds and legal-game/mod evidence; and real release assembly, signing, and publication. No deferred source has been read or imported at this checkpoint. Workflow definitions, mocks, and no-game tests are not platform, engine, mod, compatibility, or in-game proof.
