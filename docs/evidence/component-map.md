# Component map

The machine-readable map is `component-ledger.json`. At the current checkpoint, the independent client foundations implement and automate exact source pinning and offline bootstrap, deterministic OpenMW patch machinery, local protocol schemas/fixtures and a loopback fake-server harness, the pure native scaffold, the Lua architecture and source manifest, deterministic packaging and package/source audits, and pinned CI definitions.

The pure native and Lua checks remain deliberately separate from OpenMW and game proof. Run `./scripts/test/native.sh` for the direct warning-clean native suite, configure CMake with `-DLORKHAN_WITH_BOOST_BEAST=ON` for the real literal-loopback socket tests, run `./scripts/test/lua-unix.sh` on Unix when Lua is installed, or `./scripts/test/lua-windows.ps1` in PowerShell. Neither native lane compiles or binds OpenMW; Lua structural/source-manifest checks do not prove engine execution.

Deferred components are the final `SYNTH`/`Synthserver` SHA import and migration plus finalized cross-repository acceptance; clean-commit durable evidence and restart-during-an-in-flight-HTTP-request recovery beyond the now-passing full Beast-to-real-server disposable-PostgreSQL flow; exact-pin OpenMW package-registration and media VFS-versus-decoder patches plus patched/control engine builds; Windows builds and legal-game/mod evidence; and real release assembly, signing, and publication. `start-gate-blocker.md` records predecessor gate metadata and test-evidence observations, but no predecessor source has been imported or semantically copied. Workflow definitions, local runtime tests, mocks, and no-game tests are not platform, engine, mod, compatibility, or in-game proof.
