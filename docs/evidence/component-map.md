# Component map

The machine-readable map is `component-ledger.json`. The client foundations own source provenance, deterministic cache/bootstrap tooling, schemas, manifests, wrappers, and build entry points. The packaging foundation owns deterministic fixture archives, package-set linkage, SPDX SBOMs, allowlists, ownership dry-runs, and compliance audits under `scripts/package`, `scripts/audit`, and `config/packaging`. It does not import an engine, implement the native bridge, read another repository, or claim release readiness. Future implementation materializes pristine OpenMW under a generated source root and keeps ALMSIVI patches/overlays reviewable.
