# Completion and proof ledger

The authoritative rows are in `proof-ledger.json` and use the states defined by `docs/PROGRAM-PLAN.md`. `AUTOMATED` means a repeatable no-game check passed; it never means a platform build or game behavior passed. `WINDOWS BUILD PROVEN`, `IN-GAME PROVEN`, and `COMPATIBILITY PROVEN` require evidence from those exact environments. `DEFERRED` rows state their resume condition. Run manifests attest only to the command, inputs, outputs, tools, and result they contain.
